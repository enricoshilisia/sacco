# Inuka West app for Android

**Download:** [InukaWest.apk](https://github.com/enricoshilisia/sacco/raw/inuka-west-mobile/releases/InukaWest.apk)

## Install
1. Open the link above on your Android phone and download `InukaWest.apk`.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser or Files app.
3. Tap **Install**, then **Open**.

The app connects to Inuka West Empowerment Group automatically. Log in with the phone
number and password your group gave you.

## Details
- Version 0.1.0, Android 7.0 or newer.
- Signed by Inuka West Empowerment Group.
- Server: `http://inuka.20.166.120.83.nip.io:8090`. It uses plain HTTP (no certificate yet).
  Move to a real domain with HTTPS before using it for real member money.
