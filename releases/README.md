# Inuka West app for Android

**Download:** [InukaWest.apk](https://github.com/enricoshilisia/sacco/raw/inuka-west-mobile/releases/InukaWest.apk) (most phones, about 33 MB)

If it says "App not installed" or "not compatible" on an older or cheaper phone, use
[InukaWest-older-phones.apk](https://github.com/enricoshilisia/sacco/raw/inuka-west-mobile/releases/InukaWest-older-phones.apk) instead.

## Install
1. Open the link above on your Android phone and download the app.
2. Open the downloaded file. If Android asks, allow **Install unknown apps** for your browser or Files app.
3. Tap **Install**, then **Open**. It installs over any earlier version.

The app connects to Inuka West Empowerment Group automatically. Log in with the phone
number and password your group gave you.

## Details
- Android 7.0 or newer. Signed by Inuka West Empowerment Group.
- ID cards are read on the phone itself; ID photos are only sent to your group's server.
- Server: `http://inuka.20.166.120.83.sslip.io:8090`. It uses plain HTTP (no certificate yet).
  Move to a real domain with HTTPS before using it for real member money.
